1. Go to **Invoicing > Configuration > Settings**.
2. Near the end of the page, after the reporting options, tick what you need:
   - **Print Show Refunds**: credit notes print negative.
   - **Print Invoice Tax Value**: adds the **VAT** column.
   - **Print Invoice Total Value**: adds the **Total** column.
3. Click **Save**. The options belong to the current company; repeat for the
   other companies if needed.
4. Optional: go to **Inventory > Configuration > Units & Packagings**, open a
   unit and set **Report Precision** to the number of decimals to print. The
   precision is used when **Print Invoice Tax Value** is on.
