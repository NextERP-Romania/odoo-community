1. Go to **Inventory > Operations > Adjustments > Inventory Stock
   Adjustments** and click **New**.
2. Set the **Accounting Date**, the locations and, optionally, the products.
3. Click **Generate Inventory Lines** to list the stock on hand.
4. Enter the counted quantity on each line; add lines for goods found but
   not in stock. Use **Clear Inventory Lines** to start over.
5. Click **Validate Inventory**: the differences are booked and the document
   is set to *Done*.
6. Click **Print Inventory Report** to print the inventory report with the
   commission, the values found in surplus and in shortage and the net
   difference.
7. Review all counted lines in **Inventory > Reporting > Inventory Stock Line
   Adjustments History**.
