1. Install and set up the Romanian e-Factura integration (`l10n_ro_edi`)
   for the company: certificate, ANAF access and the rest of its
   configuration.
2. Go to **Invoicing > Configuration > Journals**.
3. Open each journal whose invoices must go to e-Factura, for example
   *Customer Invoices*, or a purchase journal used for self-billing.
4. Tick **Enable EDI Send** (next to **Currency**) and save.

After installation the option is off on every journal, including the ones
that used to send. Switch on the right journals right away to keep sending
without interruption. Leave it off on journals for internal transfers,
group invoices already reported elsewhere or tests.
