1. Go to **Inventory > Configuration > Settings**.
2. Below the **Operations** block, tick the options you need:
   - **Delivery Slip Report Only Name**
   - **Delivery Slip Report Uom Precision**
   - **Picking Report Lang Company**
3. Save. The options apply to the current company.

For the unit of measure precision, set the number of decimals on each unit
of measure as provided by `nexterp_account_invoice_report`.
