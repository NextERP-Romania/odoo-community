1. Create a vendor bill from **Invoicing > Vendors > Bills > New**.
2. Fill in the **Bill Date** as written on the supplier's invoice.
3. The **Accounting Date** takes the same date.
4. If that date belongs to a period closed for taxes, the accounting date is
   set to the day after the tax lock date instead.
5. Confirm the bill: the journal entry is posted on that accounting date.
