Analytic distribution models fill in the analytic distribution of
journal items automatically, based on the account, partner, product and
so on. This module adds the **Journal** as one more criterion, so a
model can apply only to what is posted in one journal.

-  A **Journal** field on every analytic distribution model, in the form
   and as a column in the list.
-  A model with a journal applies only to items posted in that journal;
   items from other journals ignore it.
-  Models without a journal keep applying everywhere, as before.
-  Useful to split costs differently per sales channel, purchase
   journal, bank or miscellaneous journal without extra rules.

Configuration
=============

1. Make sure analytic accounting is enabled: **Invoicing > Configuration
   > Settings**, section **Analytics**, option **Analytic Accounting**.
2. Go to **Invoicing > Configuration > Analytic Distribution Models**.
3. Open a model (or create one) and choose the **Journal** it is meant
   for.
4. Save.

Leave **Journal** empty on the models that should keep applying to every
journal. The **Journal** column of the list can be used to group or
filter the models.

Usage
=====

1. Create or open a document whose lines are posted in a journal pinned
   on a model, for example a vendor bill in the journal chosen on the
   model.
2. Fill in the lines as usual: the analytic distribution of the model is
   set on the matching lines.
3. Post the same kind of line in another journal: the pinned model is
   ignored and only the models without a journal (or pinned to that
   journal) apply.

Example: a *Project costs* model pinned to the vendor bills journal and
an *Operating expenses* model with no journal. A vendor bill picks up
*Project costs*; a bank or miscellaneous entry picks up only *Operating
expenses*.
