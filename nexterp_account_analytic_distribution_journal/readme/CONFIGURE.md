1. Make sure analytic accounting is enabled: **Invoicing > Configuration >
   Settings**, section **Analytics**, option **Analytic Accounting**.
2. Go to **Invoicing > Configuration > Analytic Distribution Models**.
3. Open a model (or create one) and choose the **Journal** it is meant for.
4. Save.

Leave **Journal** empty on the models that should keep applying to every
journal. The **Journal** column of the list can be used to group or filter the
models.
