The **Credit Note** dialog of an invoice offers a button that reverses the
invoice and opens a new draft invoice copied from it in a single step. Many
teams prefer each document to be issued on purpose. This module removes that
shortcut, so a reversal only creates the credit note.

- Hides **Reverse and Create Invoice** in the credit note dialog of customer
  invoices and vendor bills.
- **Reverse** stays available: the credit note is created as before.
- A replacement invoice, when needed, is created on its own, like any new
  invoice.
- Nothing to configure.
