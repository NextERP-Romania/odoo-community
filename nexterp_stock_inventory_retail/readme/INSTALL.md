To install this module, you need to:

- clone the branch 20.0 of the repository
  <https://github.com/NextERP-Romania/odoo-community>
- add the path to this repository in your configuration (addons-path)
- have `l10n_ro_stock_account_retail` available from the
  l10n-romania repository
- update the module list

The module is auto-installed as soon as `nexterp_stock_inventory` and
`l10n_ro_stock_account_retail` are both installed.
