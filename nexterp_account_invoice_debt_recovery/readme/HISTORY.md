# Changelog

## 19.0.0.1.0 (2026-11-05)

- Uninstalling the module no longer deletes the invoices left in debt
  recovery: they go back to their standard payment state (not paid, partial
  or paid).
- The Debt Recovery tab no longer carries the misspelled `invisibile`
  attribute; the technical `debt_company` field is hidden.
