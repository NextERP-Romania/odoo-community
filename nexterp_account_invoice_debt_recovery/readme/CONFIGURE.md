# Configuration

## Enable Debt Recovery per Company

1. Go to **Invoicing → Configuration → Settings**.
2. Scroll to the **Debt Recovery** section.
3. Enable **Allow Debt Recovery on Invoice** (`account_allow_debt_recovery_invoice`).
4. Click **Save**.

> This setting is stored on `res.company` and must be enabled for each company independently. When it is off, the Debt Recovery controls are hidden from invoice forms for that company.
