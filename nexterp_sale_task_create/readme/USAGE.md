## Automatic mode

1. On a quotation, check that **Auto Create Sale Tasks** (next to
   **Payment Terms**) is ticked.
2. Click **Confirm**. The tasks are created as usual, one per service line.

## Manual mode

1. On a quotation, untick **Auto Create Sale Tasks**.
2. Click **Confirm**. No task is created.
3. When the tasks should exist, open the order and click **Generate Tasks**.
4. One task is created for every service line that does not have one yet.
   Lines that already have a task are skipped, so the button can be used
   again after the order is extended.

Orders that mix services and goods only create tasks for the service lines,
in both modes.
