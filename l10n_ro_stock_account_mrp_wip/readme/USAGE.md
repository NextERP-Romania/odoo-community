First set up the WIP accounts, you can set default ones in company accounting settings,
or lower level on product category and product. On the Bill of Material set to True
"Auto WIP Accounting", so for each manufacturing order it will be generated separated
moves for work in progress. If you transfer production from other softwares, you can set
up the WIP Initial. The WIP will be calculated at every consume of raw material, and
calculate it in the actual manufacuring order. At the registration of the produced
products the WIP amount will be deducted.
