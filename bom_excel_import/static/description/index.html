BOM Excel Import

This module allows importing Bills of Materials (BOMs) from Excel files. The Excel file should have the following structure: - Column 1: Product produced - Column 2: List of operations in the BOM - Column 3: Quantity consumed in each operation - Column 4: Product/component consumed UOM - Column 5: Product/component consumed - Column 6: Workcenter - Column 7: Subcontracting (boolean) - Column 8: Subcontractors (comma-separated) The import process uses multi step wizard: 1. Import operations and workcenters 2. Import BOMs with the operations The wizard guides you through the complete process in a single interface.

Overview

Load bills of materials, their operations and work centers from one Excel spreadsheet instead of typing them in one by one. A guided wizard reads the file, creates what is missing and shows a log of every row it handled.

  • One file, all master data: produced product, operation, component, quantity, unit of measure, work center and subcontractors on one row.
  • Missing records created on the fly: unknown work centers and products are created, so a first import can set up manufacturing from scratch.
  • Subcontracting aware: a row can mark the bill of materials as subcontracted and name the subcontractors.
  • No duplicates: bills of materials and components that already exist are detected and skipped.
  • Readable log: counters and a row-by-row log of everything created, skipped or rejected.

Configuration

  1. Make sure the openpyxl Python library is installed on the server running Odoo; the wizard tells you if it is missing.

  2. Users need the Manufacturing / User access right to run the import.

  3. Prepare the Excel file with one header row and these columns, in this order:

    Column Content
    1 Product produced (name or internal reference)
    2 Operation name
    3 Quantity consumed
    4 Component unit of measure (by name)
    5 Component (name or internal reference)
    6 Work center name
    7 Subcontracting flag (any value marks the bill of materials as subcontracted)
    8 Subcontractors, comma-separated partner names

By default the wizard reads the sheet named Sheet1 from row 2; both can be changed on the upload screen.

How it works

  1. Go to Manufacturing > Products > BOM Excel Import.
  2. Attach the Excel file, adjust Sheet and Start Row if needed and click Start Import.
  3. Click Import Operations: missing work centers are created, then one bill of materials per produced product with its operations.
  4. Click Import BOMs: the component lines are added to each bill of materials, creating components that do not exist yet.
  5. Review the summary: counts of work centers, operations, bills of materials and lines created, the number of errors and both logs.
  6. Click Import Another File to start again.
