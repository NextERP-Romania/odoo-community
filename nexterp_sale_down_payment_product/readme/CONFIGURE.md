1. Create a service product to use for down payments, for example
   *Down Payment*, with the income account it should be booked on.
2. Go to **Invoicing > Configuration > Settings** (or **Accounting >
   Configuration > Settings**).
3. In the **Default Accounts** section, under **Down Payment Account**,
   select the product in **Sale Down Payment Product**.
4. Click **Save**.

In a multi-company database, switch to each company and repeat the steps.
